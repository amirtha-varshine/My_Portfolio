FEATURES

Fully responsive, single-page design across mobile, tablet, and desktop. Animated hero section with rotating role text. Skills organized into categorized cards covering languages, frameworks, databases, tools, and soft skills. Project showcase with tech stack tags and links. Embedded resume viewer with copy, open, and download options. Timeline-based professional experience section. Certification grid with issuer, year, and verification links. Education section with a CGPA progress bar and relevant coursework. Achievements and leadership highlights. Contact section with direct details and social links.

BUILT WITH

React for component-based UI, Tailwind CSS for styling, generated and iterated using Google AI Studio.

PROJECT STRUCTURE

public folder containing resume.pdf, certificates, and projects subfolders. src folder containing a data folder with profile.js, projects.js, and certificates.js, a components folder, and App.jsx. Root level contains package.json and README.

GETTING STARTED LOCALLY

Clone the repository using git clone, followed by the repository URL. Navigate into the project folder. Install dependencies using npm install. Run the development server using npm run dev.

DEPLOYMENT

This project is deployed via Google AI Studio. To redeploy after changes, run npm run build followed by npm run deploy.
